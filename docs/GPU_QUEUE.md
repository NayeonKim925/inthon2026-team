# GPU 예약과 결과 공유 양식

GPU 한 대면 이 양식을 팀 채팅 또는 공유 문서에 복사해 사용합니다. Git 파일을 네 명이 실시간으로 수정할 필요는 없습니다.

| 순서 | 담당 | 작업 / 실험 ID | 시작 예정 | 예상 소요 | 상태 | 결과 위치 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | A | baseline smoke | 팀에서 결정 | 미측정 | 대기 | |
| 2 | 팀에서 결정 | baseline 전체 특징 추출 / SigLIP 확인 중 우선순위 합의 | | 미측정 | 대기 | |

## 실행 전

- 다른 사람의 작업이 종료됐는지 확인합니다. 다른 프로세스를 임의로 종료하지 않습니다.
- 실행 명령, 실험 ID, 예상 시간, GPU를 점유할 구간을 알립니다.
- 특징 추출이 끝난 뒤 작은 MLP를 CPU에서 학습해도 되는지 측정해 결정합니다.

## 결과 공유 메시지 양식

```text
담당/실험:
현재 상태: 개발 중 / 실행 중 / 완료 / 막힘
변경한 점:
코드 브랜치·commit 또는 PR:
공통 검증 버전·점수:
시간·메모리:
가중치 위치(비공개 채널):
다른 팀원에게 필요한 행동:
GPU 반납 여부:
```

대략 1시간마다 또는 작업 완료·막힘 발생 시 공유합니다. 제출 횟수와 최종 선택 모델은 A가 한곳에서 관리하고 같은 후보를 중복 제출하지 않도록 합니다.
